المجالات

الرياضيات — السنة الأولى ثانوي

📚 ما هو المجال؟

المجال هو مجموعة من الأعداد الحقيقية التي تقع بين حدّين معينين، وقد تكون الحدود داخلة في المجال أو غير داخلة فيه.

نستعمل المجالات كثيرًا لكتابة مجموعة من القيم التي تحقق شرطًا معينًا.

🔢 أنواع المجالات

المجال المغلق

عندما يكون الطرفان داخل المجال:

[a ; b]

يعني:

a ≤ x ≤ b

المجال المفتوح

عندما لا يكون الطرفان داخل المجال:

]a ; b[

يعني:

a < x < b

مجال مغلق من اليسار

[a ; b[

يعني:

a ≤ x < b

مجال مغلق من اليمين

]a ; b]

يعني:

a < x ≤ b

💡 أمثلة محلولة

مثال 1:

لدينا:
x ∈ [2 ; 7]
هذا يعني:
2 ≤ x ≤ 7
أي أن العدد x أكبر من أو يساوي 2، وأصغر من أو يساوي 7.
مثال 2:

لدينا:
x ∈ ]-3 ; 5[
هذا يعني:
-3 < x < 5
أي أن -3 و 5 غير داخلين في المجال.
مثال 3:

لدينا:
x ∈ [1 ; 6[
إذن:
1 ≤ x < 6
العدد 1 داخل المجال، أما 6 فليس داخله.

♾️ المجالات غير المحدودة

يمكن أن يمتد المجال نحو ما لا نهاية.

أكبر من a

]a ; +∞[

أي:

x > a

أكبر من أو يساوي a

[a ; +∞[

أي:

x ≥ a

أصغر من a

]-∞ ; a[

أي:

x < a

أصغر من أو يساوي a

]-∞ ; a]

أي:

x ≤ a

🧠 كيف أميز المجال؟

تذكر:

[ أو ] عند الطرف تعني أن العدد داخل المجال.

أما الطرف المفتوح مثل: ] أو [ فيدل على أن العدد غير داخل المجال.

وعند +∞ و -∞ نستعمل دائمًا طرفًا مفتوحًا.

✏️ تمارين تفاعلية

التمرين 1: اكتب المتراجحة التي تمثل المجال:

x ∈ [3 ; 8]

3 ≤ x ≤ 8

التمرين 2: اكتب المجال الذي يمثل:

-2 < x ≤ 5

x ∈ ]-2 ; 5]

التمرين 3: هل العدد 4 ينتمي إلى المجال:

]1 ; 4[

لا، لأن المجال مفتوح عند 4.

التمرين 4: اكتب المجال الذي يمثل:

x ≥ 2

x ∈ [2 ; +∞[
